# 匹配状态响应与手指限位定位（2026-10-02）

**本轮找到一项对转向偏差有实测贡献的物理迁移差异：部分手指目标越界时，PhysX把关节保持在限位附近，当前MuJoCo的软限位允许明显越界。** 只改变限位约束参数、保持权重和目标生成规则不变，零转向指令下的右偏减少约78%（vx0.5）/62%（vx1）。四个手指关节的组合产生了与全部14个手指完全相同的轨迹效果；没有一个单关节能单独消除偏差。

这不是“整侧肌力较弱”的证据。左右配置及小动作响应此前已核对；关键区别出现在较大的、部分越界的策略目标下。改限位后前向速度RMSE明显增大，因此**不接受为默认修复，不冻结baseline**。偏差仍非零，也不能宣称全部根因已解决。

## 1. 回答“是否直接复制强侧或弱侧权重”

不应这样做，也不能认为复制哪侧都无所谓。当前actor是共享全连接网络，实际权重形状为256×123、128×256、128×128、37×128，隐藏单元混合使用两侧关节与机体状态；不是两套独立的左右网络。

正确的镜像关系是：把状态和任务指令一起镜像后，输出动作也应镜像，即`policy(mirror_observation) = mirror_action(policy(observation))`。这不要求同一时刻左右腿动作相等。左右交替迈步、支撑与摆腿阶段本来不同，转向任务本来需要左右差异；直接复制一侧动作/输出权重可能破坏这些关系。即使通过结构约束或策略镜像平均实现这个关系，也不自动保证稳定性、目标跟踪或保持原步态，本轮未做这些改动。

## 2. 新的真实 Isaac 采集

42个并行独立诊断条件，物理dt0.005s，每条件200ms、41个采样。39个默认姿态控制/小动作条件（1个保持、36个左右关节单独小动作、torso关节正负2个），另3个实际Isaac行走状态。

单关节目标偏移0.01rad；位于关节边界的手指采用可行方向，左右按实际镜像符号配对。实际状态来自固定本地1499的既有interface_live/baseline1499.npz采样50/100/150；读取相应关节位置/速度、基座状态和记录的关节目标，将根平移至2m，保持原姿态、速度及目标，观察悬空响应。新采集不加载actor、不训练、不开策略反馈。所有条件gravitydisabled、自由基座；实际42×41样本接触力为0，关节摩擦系数为0。

首次采集t0读到重置前的接触力缓存，守卫中止。保留该不完整记录与原源码于matched_actuation_isaac_aborted_sensor_guard；将生成环境时的初始高度也直接设为2m后，重新完整采集，所有样本接触力0。未把不完整记录作为有效实验。

## 3. MuJoCo 匹配状态和时刻

同一USD-position模型、相同关节顺序/初始位置速度/固定目标，gravity0、无接触；两种回放：5ms匹配Isaac物理步长，1ms细分但仍每5ms采样。初始根部状态需区分：Isaac root_state_w为linkpose+COM世界速度；MuJoCo freejoint角速度分量是局部坐标。采用明确的root_link_state_w速度初始化，再独立核对COM位置和速度。COM姿态不直接比较，因为两个引擎惯性坐标帧约定不同。

42个初始状态：COM位置最大误差2.41e−7m，COM速度最大误差1.58e−7，44个身体link位置最大误差1.18e−6m。实际Kp/Kd/armature/力上限与MuJoCo匹配，初始条件和输入目标检查通过。PhysX ImplicitActuator的computed/applied torque是估计值，因此**没有冒充实际驱动力矩**；本轮主要比较关节响应，MuJoCo保存的力矩用来核对其自身限幅。

默认姿态小动作：全关节位置响应最大跨引擎差异约0.000370rad（5ms Mu）或0.000145rad（1ms Mu）。这不能排除大动作、饱和、限位、接触等不同工作区间的差异。

## 4. 实际策略目标下的手指限位差异

三段实际行走状态的held-target回放中，right_four、left_six、right_six、left_four目标均朝着限位外侧。例：walking_state_100，right_four范围[0,1.84]rad，目标−1.53460rad，初始位置约0。PhysX在200ms末仍约−7e−7rad；原MuJoCo5ms回放约−0.51327rad。对应1ms回放的最大手指差异达到0.54123rad。

腿部响应也有差异：三段5ms回放各自最大约0.0145/0.0377/0.0111rad，并非所有动力学已经等价。但手指差异特别大且集中在上述4个关节，为物理单变量实验提供了具体依据。

MuJoCo约束参数solref的正值格式控制约束时间常数和阻尼；较大的时间常数意味着较软的约束，默认solref为[0.02,1]。时间常数不能任意小于物理步长的两倍，默认refsafe规则会约束过小值。因此在5ms和1ms下写入同样的0.002，不能宣称得到同样有效刚度。[MuJoCo官方建模说明](https://mujoco.readthedocs.io/en/stable/modeling.html#solver-parameters)

诊断只将14个手指的jnt_solref第一项0.02改为0.002，角度范围、Kp/Kd、armature、力上限、目标、接触和权重不变。三段实际目标响应中最大手指误差：5ms从0.51327降至0.30320rad，1ms从0.54123降至0.01450rad。未彻底匹配PhysX限位，也不把这个探索参数当成已校准物理真值。

## 6. 结论与下一步

本轮支持的因果范围：4个手指的限位响应差异会通过闭环动力学/观测影响右偏；尚未区分手部惯性作用与手指观测反馈两条路径，也未完全解释剩余偏差。输入接口此前同状态审计一致，而物理响应在限位区间确有差异；不能直接靠复制一侧权重来修复它。

下一步固定1499，继续校准限位区域的响应，区分物理运动与观测反馈对行走的贡献，再在接触条件下比较腿部大动作、限幅和约束响应。必须联合评估前向速度、航向、倾角和终止，不能只按yaw改善选参数。只有这些物理/接口差异清楚后，再决定是否需对称训练或迁移鲁棒性训练。暂不修改训练权重、默认部署或supervisor/fallback。
