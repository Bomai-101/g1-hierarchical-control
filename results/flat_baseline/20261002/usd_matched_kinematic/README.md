# USD 对齐的独立 MuJoCo 模型：运动学阶段完成

已经生成独立 MuJoCo 关节树，采用 Isaac USD 原始父/子关节坐标与参考零位，包含 44 个身体、37 个转动关节及 6 个固定连接。
原始参考模型、默认控制入口、两个策略及此前回放保持不变。没有训练、commit 或 push。

## 核验结果

将 Isaac 已有真实回放的根部姿态与关节角代入新 MuJoCo 模型，只调用 `mj_forward`，不执行物理步进。
使用 1499 与 1999 两个模型各 401 个状态，核验全部 35,288 对身体姿态。使用 1999 是为了扩大姿态核验范围，不表示其通过迁移验收。

| 检查项 | 结果 |
|---|---:|
| 1499 全身最大位置误差 | 3.128 µm |
| 1999 全身最大位置误差 | 3.181 µm |
| 最大旋转矩阵元素误差 | 2.035e-6 |
| 默认姿态左脚原点误差 | 0.311 µm |
| 默认姿态右脚原点误差 | 0.309 µm |
| 64 组随机关节角，相对独立 USD 正运动学最大数值差 | 1.444e-15 |

上一轮原始 MuJoCo 模型的默认脚部原点差约为 56.708 mm。本轮将同一套关节角解释成了一致的身体姿态。
这不是行走回放结果，也不能说明原来的偏航或跌倒已经修好。

## 实际质量、质心与惯量

另启动一次 Isaac 环境初始化，读取 PhysX 实际质量、COM 和惯量；没有加载或执行策略。
实际总质量为 32.238926766 kg。两个 USD 自动质心部件 `pelvis_contour_link` 与 `imu_link` 的实际局部质心均为 `[0,0,0]`，使用真实值，不以推测替代。
实际惯量张量已在部件 actor 坐标中表达，依据本地 IsaacLab `ArticulationData.default_inertia` 文档，不能再使用 COM 主轴四元数旋转一次。
只为浮点非对称误差取张量对称部分，然后用 MuJoCo `fullinertia` 导入。

编译后逐个核验 44 个部件：质量最大差 0，COM 最大差 0，惯量张量最大差 `5.552e-17 kg·m²`。
保留固定部件，关闭编译器固定体融合；二进制模型与 XML 重新编译后的所有模型数组一致。

## 模型范围

这是**运动学核验模型**：保留原始 USD 视觉网格，所有视觉几何接触掩码为 0，没有执行器和接触几何，重力为 0。
质量和惯量的正确导入为下一阶段准备数据，当前模型不用于策略行走、动力学性能评估或机器人部署。
没有把此阶段的姿态对齐称为单变量动力学实验。

生成文件位于本地被 Git 忽略的目录：

`code/day9/g1_balance/checkpoints/flat_baseline/20261002/usd_matched_kinematic/g1_usd_matched_kinematic.xml`

同目录 `.mjb` 保存编译模型及嵌入网格。XML 使用既有本地视觉网格目录，单独拷贝 XML 不能保证可移植性。
实际 PhysX 属性位于 `usd_matched_properties/`；本目录 `evidence/` 归档对应 JSON、构建说明与源码哈希，不复制原始机器人网格。
