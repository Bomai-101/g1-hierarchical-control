# 物理对称性与策略镜像对照（2026-10-02）

**本轮修正此前判断：测得的稳定右偏不能简单理解为“物理模型无论怎样控制都固定向右偏”。** 在同一个不变的物理模型中，只对策略输入/输出做左右镜像，偏差就变为幅度接近的左偏。因此，偏差与控制策略及其在当前动力学中的响应有关；结合前轮同权重在Isaac偏差较小的证据，更适合描述为**策略与迁移动力学的交互偏差**。尚未确定哪项PhysX/MuJoCo差异在放大它，也不能因此排他归因到权重或认定需要重训。

本轮不使用指令偏置补偿。固定我们按参考流程训练的1499权重；不是参考提供权重，不是续训1999。所有新变体只在内存中用于诊断，不写回原MJB或部署默认配置。镜像策略不改权重，但会改变控制行为，不是“策略完全不变”的对照。

## 1. 物理配置的左右镜像审计

从默认姿态的实际编译模型核对：19对左右身体的质量、世界位置/质心、世界惯量均满足矢状面对称（最大惯量差约浮点精度）；37关节的镜像映射，包括左右交换和相应符号，关节轴、默认角度、限位、armature、执行器gain/bias、力上限一致。两只脚碰撞网格世界顶点集合镜像Hausdorff误差0，摩擦、接触维数、求解参数和碰撞mask一致。

中间部件并非绝对对称：躯干COM侧向偏移2.669mm、头部0.284mm、logo0.056mm，默认全身COM偏移0.535mm；中心惯量也有少量非对称分量。这些由实际PhysX运行属性复制，前轮已核对，**不是本轮发现的导出错误**。纯属性审计不能证明动力学等价。

## 2. 16次20秒行走对照

vx=0.5/1m/s，任务指令[wz=0,vy=0]，根初始高度0.74m、航向0、原默认关节姿态，平地摩擦0.8，物理1ms、策略20ms，确定性actor，无扰动。没有航向反馈或偏置补偿。评分为末10秒展开航向对时间的最小二乘斜率；正值向左、负值向右，不把body angular z当作航向变化率。

各独立诊断条件：

- Baseline：当前USD-position模型与原actor。
- setConst control：只重算MuJoCo依赖常量，不改输入物理属性，用于排除重算流程本身的影响。
- Central COM symmetric：只去掉中心部件的侧向COM偏移，质量/惯量不变。
- Central inertia symmetric：只去掉中心世界惯量中关于矢状面的非对称分量，COM/质量不变。
- Contact time0.01：仅将所有有效碰撞geom的solref第一项从0.02改为0.01，其他接触参数不变；不是已校准的PhysX对应值。
- Elliptic cone：只改摩擦锥求解表示。
- Implicit integrator：只由implicitfast改为implicit，不更改servo、Kp/Kd或步长。
- Mirrored controller：模型完全不变，策略输入与输出做左右镜像，权重不变。

COM/惯量修改后调用mj_setConst重算相关惯量依赖数组；这类派生数组的变化逐项记录，不能误称“编译模型只有一个数组变了”。本轮第一次运行的严格数组检查因未列出这些依赖而中止；仅完成2组基准，原记录/源码保留于usd_physics_isolation_aborted_setconst_guard，未作为完整实验统计。修正依赖清单并加入setConst-only对照后，全16组重新执行。

上述物理变体和流程对照没有消除右偏；它们的影响有限，但**不能排除更广泛的接触参数、执行器实现或其他迁移差异**。中心小不对称不支持作为当前偏差的主要解释。

镜像策略是本轮关键：同一个物理模型上，原策略−0.09087/−0.10087，镜像策略+0.09162/+0.10229 rad/s。这个近似反向关系不支持“物理模型有独立于控制器的固定右向缺陷”这一简单解释，支持偏差与策略行为有关。它不能证明策略单独有错、不能证明模型正确或PhysX/MuJoCo动力学一致。镜像策略仍然走偏，只是反向，**不是修复候选**。

镜像实现：机体线速度和重力向量取[x,−y,z]，角速度取[−x,y,−z]；指令[vx,vy,wz]取[vx,−vy,−wz]；37个关节位置偏差/速度/上一动作按实际镜像轴交换左右并变换符号，中央waist轴也处理；actor输出作逆映射。映射作用两次必须恢复原输入，本轮100个随机123D输入通过。只交换左右脚而不处理轴符号是不正确的，故未使用那种简化。

16/16均完成20秒（1000动作、1001采样、20000物理步），没有根高度<0.35m或非有限/BADQPOS/BADQVEL/BADQACC终止，无重置；不等价于全面无跌倒、安全性或鲁棒性结论。两组baseline与上一轮20秒原始记录的全部NPZ数组完全一致；setConst-only的全部数组也与本轮baseline一致。

## 3. 无策略、无接触的左右关节短时响应

两种积分器（implicitfast/implicit）×左右6对髋pitch/roll/yaw、膝、踝pitch/roll，24条响应。根悬空2m，自由漂浮、重力0、无接触；默认关节姿态，每次一个关节加镜像0.01rad目标，其他37位置servo目标保持默认，观察200ms。真实中心不对称保留，不运行policy。

初始力矩与Kp×目标偏差一致，实际力矩均在模型配置上限内。所有37个关节的镜像位置响应最大差异 **3.701e−6 rad**（约0.000212°），没有显示明显的左右servo响应不一致。位置、速度、力矩的成对数值见actuation_probe.json。

这只检查当前MuJoCo内部的左右短时响应，**不是与PhysX的匹配状态响应对比**，也不能验证地面接触步态。这是下一步缺少的关键证据。

## 4. 下一步与范围

下一轮固定1499，在真实Isaac状态下施加相同关节目标，构造对应MuJoCo状态，先比较无接触的一步/短时响应，再加入双脚接触。需要明确基座原点与COM速度转换、自由关节角速度坐标、两引擎步长与采样时刻，并核对目标/初始力矩。定位到实际响应差异后，才做有依据的单变量物理调整。暂不重训、不默认启用补偿、不冻结baseline、不启用supervisor/fallback。

当前能确认的是偏差与策略行为有关，迁移动力学可能放大这种行为差异。尚没有唯一根因；不能把镜像反向当成“训练失败”的证据，也不能把未消除偏差的几个参数测试当成已排除所有物理问题。
