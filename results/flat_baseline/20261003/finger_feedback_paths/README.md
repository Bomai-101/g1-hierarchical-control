# 四手指物理路径与观测路径分离（2026-10-03）

**结果：在本轮诊断中，转向与速度表现主要跟随策略读取的手指状态，而不是只跟随实际手指限位的软硬。** 原软限位物理模型读取紧限位下的手指位置/速度后，表现接近紧限位方案；紧限位物理模型读取软限位状态后，表现回到原方案。同一状态下，仅替换8个手指观测值，也会改变腿部动作输出。

这解释了“手指看起来与行走无关”的疑问：本轮不支持手指在承担支撑行走的作用，关键可观测路径是**手指位置/速度 → 共享策略网络 → 腿部目标 → 行走变化**。是否通过其它机械耦合产生更小影响未完全排除。不能说手指是全部根因，不能据此删除观测维度或直接复制左右权重。

本轮固定我们本地训练的1499 NPZ、同一USD-position物理模型。无新训练、heading反馈、指令偏置、supervisor/fallback或部署默认值修改。现有被动locomotion shadow模块未修改；本轮主动改动实验策略输入，不属于无干扰监测验证。

## 1. 诊断设计：实际物理条件与输入来源分开

四个关节：left_four、right_four、left_six、right_six。实际主模型分两种：原soft限位参数，或仅将这4个关节jnt_solref第一项0.02改为0.002的tight参数。角度范围、Kp/Kd、armature、模型质量/惯量、其他关节、碰撞/接触、actor权重不变。

每条主回放同时运行一个采用相反限位参数的条件模型，二者每个物理步采用相同37个关节目标。条件模型只保留自己的4个手指位置/速度；每步结束后将其余全部qpos/qvel重置为主模型当前值，避免第二模型在无独立反馈控制时偏离步态。主模型始终真实执行其自身动力学，不从条件模型复制任何实际状态。

策略观测有两种来源：

- self：完整原123D观测来自主模型。
- paired：仅替换上述4关节的位置偏差与速度，共8个字段；其它关节、根部速度/重力、任务指令以及全部37维上一动作仍来自主模型。

八个索引以complete.json的observation_slots为准，采用原metadata关节顺序；不改变维度或缩放。目标仍为default+0.5×actor动作。物理条件或观测变动后闭环动作自然变化，不能称为逐帧相同动作的对照。

**条件模型是人工诊断状态生成器，不是第二个真实机器人或严格保持动量的完整反事实物理世界。** 非手指状态移植是一项明确干预。结果支持当前输入路径的重要性，不提供天然机械/传感贡献的可相加百分比分解。

首次探索曾让第二模型完整自由演化；它在开环目标下失去站立姿态，故未用作主因果证据。完整探索记录/旧源码保留于finger_feedback_paths_unsynchronized_exploratory，原源码哈希匹配旧inputs。随后完成所有8组同步条件模型回放。

## 2. 八组20秒回放结果

平地、摩擦0.8、初始根高度0.74/yaw0/原默认姿态，vx0.5/1，vy0/wz0，physics1ms/policy20ms，无heading反馈或偏置。末10秒评分；展开航向对时间的OLS斜率是实际方向变化率，负值向右。单一确定性初始条件，不是随机鲁棒性试验。

两次交叉替换的结果均更接近手指观测来源对应的方案。特别是tight物理读取soft状态时，右偏与速度都接近原soft；说明原物理动作本身不是独立决定这个表现的唯一条件。物理限位不匹配导致的手指状态变化，会作为策略输入影响腿部控制。

soft-self与tight-self的主模型时间、qpos/qvel、信号、全部动作和峰值力矩分别与前轮baseline、active4逐数组完全一致。新增条件模型运算没有扰动这些控制组的主轨迹。8/8主模型及同步条件模型均完成20秒：1000动作、1001状态、20000物理步；无根高度<0.35m或数值异常终止，条件模型未低于高度终止阈值。此有限终止检查不能当成全面无跌倒/安全性结论。

所有保存采样中，条件模型非4手指的qpos/qvel与主模型逐位一致，根位置差为0；代码每个物理步同步，原始记录每20ms保存一次，不能声称独立保存/重建了每个1ms状态。

## 3. 同一状态的网络输出核验

在每个保存的策略时刻分别计算actor(actual_obs)和actor(used_obs)。两次推理的身体/腿部状态、任务和37维上一动作完全相同，仅8个字段不同。这是即时输入干预，避免拿不同轨迹上的动作直接相减。

在4条交叉替换回放中，12个腿部关节动作变化RMS为0.06435～0.07373，乘0.5动作缩放对应目标位置RMS约0.0322～0.0369rad（约1.84～2.11°）；最大单腿关节目标变化约0.1227rad（7.03°）。self控制组两次输入相同，输出差为0。

这直接证明当前共享MLP对这些手指观测有敏感性，腿部输出确会改变；**不证明网络有意把手指用作步态信号，也不提供训练分布统计或唯一根因判断**。前轮实际PhysX手指常停在限位附近、Mu允许越界，提供输入分布迁移失配的线索，仍需结合真实行走观测进一步评估。

## 4. 范围与下一步

tight观测对应更小右偏，但前向速度误差依旧更大。观测替换不是已验证的控制方案，本轮没有把它或tight限位设为默认。原123D网络不能随意删掉手指维度；固定/裁剪手指输入会改变策略语义，必须单独评估，不能视为无干扰监测。

下一步回到腿部和脚底接触：在真实Isaac单/双支撑状态下，以相同目标做短时MuJoCo对照，明确接触、腿部大动作/饱和及基座速度响应差异。继续同时评估前向速度与航向，不凭单项偏差减少冻结baseline，不急于重训或左右权重复制。
