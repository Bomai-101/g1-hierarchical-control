# 首轮技能与交接分离诊断

冻结首轮 hold/march model_999、原1499、物理模型、接口和原验收标准。不训练、不部署、不 commit/push。

两个引擎分别执行：
- Static：默认重置姿态、零根速度/关节速度，t=0直接启动候选，无1499前序，无动作混合。这是冷启动能力测试，不等于从已经稳定的站姿进入。
- Direct：1499按原速度/yaw前序执行，在5.22/5.44s（Mu）或5.22–5.52s（Isaac16环境）交接，保留原0.5s动作混合。
- Ramp0.5/Ramp1.5：从与direct相同的决策状态开始，1499输入的vx和yaw线性降至0，然后交接，保留原0.5s动作混合。降指令不代表实际身体已减速；记录实际接手速度。

Mu每技能38案例，Isaac每技能19命令组×16环境。速度.5与1m/s分开（1m/s仍为训练范围外压力）；yaw=-.2/0/+.2；不同交接时间/踏步相位。Seed42；平行环境/相位差不是独立随机seed。

每个实际交接后观察10s，失败后不计重置数据。原共同验收标准不变。额外从最初减速决策时刻计位移/航向/制动距离，避免只从延迟交接开始计分而隐藏制动成本。最后两秒指标只对完整10s存活案例用于比较，短失败尾窗不等价。

核验：运行输入SHA；源/版本/配置；123D公共观测、125D相位适配、网络输出、连续动作混合、前动作反馈；原指标重算；脚接触转换/抬脚；各环境减速前状态/动作逐数组一致；direct与原首轮trace一致。各引擎物理步长与足接触定义仍分别记录，不当作同一物理模型。

因果限制：ramp同时改变速度、步态相位、姿态及策略历史；若存活改善，只能证明该交接协议影响结果，不能证明单独某个关节或速度是唯一原因。静止启动也不能代替行走交接验收，存活也不能代替稳定停车/原地踏步。
